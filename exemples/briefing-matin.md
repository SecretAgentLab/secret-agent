# Briefing du matin, exemple réel anonymisé

```
Bonjour,

Météo du jour : ciel couvert, 11°C le matin, 16°C l'après-midi,
pas de pluie prévue avant le soir.

Agenda du jour :
- 09h30 : rendez-vous professionnel
- 14h00 : créneau libre
- 18h00 : engagement personnel

Tâches en attente depuis hier :
- 1 message à renvoyer
- 1 document à relire

Rien d'urgent signalé sur les tâches planifiées de la nuit.
```

## Ce que cet exemple montre

Le message est court par construction : météo, agenda, tâches en attente,
rien d'autre, livré une seule fois sur le canal attendu. Pas de récapitulatif
après coup, pas de doublon sur un second canal : c'est précisément la règle
née de l'un des incidents documentés dans le README principal, des messages
qui arrivaient en double sur deux canaux différents avant qu'une règle de
cloisonnement strict ne soit écrite.
